# 📚 Lumina Books - Premium Online Bookstore

Lumina Books is a modern, responsive web-based bookstore application built with **PHP**, **MySQL**, **Tailwind CSS**, and **Vanilla JavaScript**.

---

## ✨ Features

- 🎨 **Modern & Vibrant UI**: Styled with Tailwind CSS, custom glassmorphism, and responsive design system.
- 📖 **Product Catalog**: Explore featured books, best sellers, categories, and flash deals.
- 🛒 **Shopping Cart & Checkout**: Interactive cart management with dynamic badge counters.
- 🔐 **User Authentication**: Secure user registration, sign-in, and profile security settings.
- 🛡️ **Admin Panel**: Dedicated dashboard for bookstore management.
- ⬆️ **Interactive Back-to-Top**: Custom mouse scroll indicator button for smooth navigation.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, Tailwind CSS, Font Awesome 6.4, Custom CSS
- **Backend**: PHP 8.x
- **Database**: MySQL (`lumina_books_db`)

---

## 🚀 Quick Setup Instructions

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/priya-pandey25/bookstore.git
   ```
2. **Move to Web Server Directory** (XAMPP / WAMP / Laragon):
   - Place project inside `htdocs/bookstore` directory.
3. **Database Configuration**:
   - Start Apache & MySQL in XAMPP.
   - Access `http://localhost/bookstore/install.php` to seed initial database tables and sample books.
4. **Run Application**:
   - Open browser at `http://localhost/bookstore/index.php`.
